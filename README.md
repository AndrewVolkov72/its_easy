# Тестовое задание для "Это Легко"

Консольная программа на Node.js для измерения скорости скачивания файлов по URL.

Программа выполняет 10 последовательных HTTP-запросов, дожидается полной загрузки каждого ответа и собирает статистику.

## Возможности

- Принимает URL через консоль.
- Выполняет 10 последовательных GET-запросов.
- Измеряет время каждого скачивания.
- Определяет размер каждого ответа.
- Рассчитывает среднее время запроса.
- Рассчитывает общий объём скачанных данных.
- Вычисляет среднюю скорость скачивания.

## Требования

- Node.js версии 20 или выше.
- npm.

Дополнительные зависимости не требуются.

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/AndrewVolkov72/its_easy.git
   ```

2. Установите зависимости:

   ```bash
   npm i
   ```

3. Запустите программу:

   ```bash
   npm run dev
   ```

4. Введите URL файла, который необходимо скачать:

   ```text
   Введите URL: https://example.com/image.jpg
   ```

*Значения приведены для примера.*

## Единицы измерения

- Время запросов — миллисекунды (мс).
- Общий объём данных — мегабайты (МБ, фактически MiB: 1 MiB = 1024 × 1024 байт).
- Скорость скачивания — MiB/s (мегабайты в секунду).

Средняя скорость рассчитывается как отношение общего объёма скачанных данных к общему времени выполнения десяти запросов.
